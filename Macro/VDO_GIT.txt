================================================================
VDO · SINCRONIZAR CON GITHUB (AGNÓSTICO AL SO)
================================================================

El repo es agnóstico: guarda contenido relativo, no rutas. Las rutas
(macros, user.cfg, repo) se detectan con vdo_paths.py, así funciona
igual en FreeCAD nativo, flatpak, snap, Windows o macOS.

Herramienta única:  vdo_sync.py
  (dentro de FreeCAD:  Macro → Ejecutar → vdo_sync.py)

----------------------------------------------------------------
RUTAS
----------------------------------------------------------------
  python3 vdo_sync.py paths        # muestra qué detecta

Si no encuentra el repo, guardalo una vez:
  python3 vdo_sync.py init --repo /ruta/a/veta-dora-freecad-config
  (o exportá la variable de entorno:  VDO_REPO=/ruta/...)

----------------------------------------------------------------
SUBIR  (macros locales -> repo -> GitHub)
----------------------------------------------------------------
  python3 vdo_sync.py publish
    = push (macros->repo) + inject (toolbar) + git add/commit/push

Solo copiar macros al repo (sin git):
  python3 vdo_sync.py push

----------------------------------------------------------------
BAJAR  (GitHub -> macros locales)
----------------------------------------------------------------
  cd /ruta/al/repo
  git pull
  python3 /ruta/al/repo/Macro/vdo_sync.py pull

  OJO: bajar PISA los archivos locales. Subir antes de bajar.

----------------------------------------------------------------
TOOLBAR / CONFIG
----------------------------------------------------------------
  python3 vdo_sync.py inject

  La toolbar es CÓDIGO portable (vdo_toolbar_inject.VDO_MACROS). Se
  inyecta en el user.cfg LOCAL. NO se versiona user.cfg (antes traía
  rutas absolutas de otra máquina: /home/javi/...).

----------------------------------------------------------------
NOTAS
----------------------------------------------------------------
- vdo_publish.py (dentro de FreeCAD) hace lo mismo que 'publish'.
- Rutas detectadas: native  ~/.local/share/FreeCAD/...
                    flatpak ~/.var/app/org.freecad.FreeCAD/data/FreeCAD/...
- Si agregás subcarpetas dentro de Macro/, incluí también su copia en
  el patrón de vdo_sync (hoy copia archivos sueltos).
